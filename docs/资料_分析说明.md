## 0. 设备与目标

- **目标机**: HONOR FNE-AN00, kernel **5.4.289-qgki** (lahaina/SM8350), KASLR on, SELinux enforcing。
- **漏洞**: CVE-2026-43499 "GhostLock" —— futex PI waiter 结构 UAF。waiter 阻塞在 `FUTEX_WAIT_REQUEUE_PI` 后返回用户态，`p->pi_blocked_on`（task+0x990）指向已释放的内核栈帧；用 `MCAST_JOIN_SOURCE_GROUP`(optname 46) setsockopt 的 gsr 拷贝在同一栈位置重灌残留（waiter 自己的 syscall 才能打到该栈区），再通过 prio 变更触发 `rt_mutex_adjust_prio_chain` 走到对残留节点的 `rb_erase`，实现**两次内核写**。
- **目标**: W1 写 `selinux_state.enforcing = 0`（位于 `.bss`，可写，flags WAX），W2 写 `init_cred` 指针进 `p->cred` → 临时 root (`adb shell id`)。
- **image base（无 slide）**: `0xffffffc010080000`；`selinux_state = 0xffffffc012c8e000`（ELF 符号 `T`，`_edata=0x12c8d200`，`empty_zero_page=0x12c8f000`）。运行时所有地址 + slide（KASLR 由 KernelSnitch 暴力恢复，**每次尝试都重跑 KS brute**，约 40–60s/次）。

## 3. 利用架构（当前实现）

线程模型（`main.c`）: owner(O1锁目标→O2→O3链锁) / waiter(M4 `FUTEX_WAIT_REQUEUE_PI`→**重灌残留**→M4b unlock→carrier) / consumer(C1 punch=`sched_setattr`改prio→C2) / main(M5 demote owner 到 SCHED_BATCH→M6 `FUTEX_CMP_REQUEUE_PI`)。route 循环 = cycle1(UMH/fops重定向, mode4) + W1×5(selinux, mode1) + W2(cred, mode2)。

**残留几何**（fops.c:364-380 注释，llvm-objdump 实测）:
- waiter 栈顶 A；futex 帧 stale waiter = A-0x1A0；gsr 拷贝 = A-0x260；`shift=24` → 拷贝+0xC0 = stale 精确对位。
- **stale waiter（compact 布局）**: `+0x00..+0x10` 锁树 rb 节点(w[0..2]=0,0,0)；`+0x18..+0x28` PI rb 节点(w[3..5]=0,0,0)；`+0x30` w[6]=task(=`fake_task` 或 `INIT_TASK`)；`+0x38` w[7]=`fake_lock`；`+0x40` w[8]=prio(GL_CHAIN_BAIL)；`+0x48` w[9]=0。
- `x24`(链的 lock 参数) = **调用方从残留里读出的 `waiter->lock` = fake_lock**（UAF 的意义所在）。

**双写原语**（PI erase, `rb_erase(node=fake_w0+0x18, &p->pi_waiters)`）:
- node 字段: `[+0x18]`=pc(=target-8), `[+0x20]`=right(child), `[+0x28]`=left。
- mode1(W1): pc=`target-8`=`state-7`（rb 擦除时 `rb_parent()` 去色位 → `&~3` = state-8），right=`base+0x40`, left=0 → 落点 **`[state+0] := base+0x40`**（child byte0=0x40→disabled 真值、byte1=base bit15 必须 0→enforcing:=0、byte3=base bit24 必须 1→initialized 保持（否则 ~2s 看门狗）；页选关卡在 `prepare_kernel_page` util.c:822，p≈1/4，坏页 pr_warning 重刷 KS）+ 附带 `[base+0x40] := state-8`（页内填充，无害）。⚠️ 旧设计 `base+0x100` 在 FNE 上 byte1 恒非 0 → 已废弃。
- mode2(W2): child=`INIT_TASK`, parent=`task+0x878` → 落 `[task+0x880] := init_cred`，附带 `[init_cred+0] := pc`（usage 损坏可接受）。
- mode4: child=`fake_fops`, parent=`misc+8` → 落 `[misc+0x10] := fake_fops`（fops 重定向），附带 `[fake_fops+0] := pc`。
- **方向与 H80GT 相反**（H80GT: pc=值、left=目标、right=0，`str pc→[child]`）；本实现: pc=父指针、right=child、left=0，`str child→[parent+8]` + `str pc→[child]`。
